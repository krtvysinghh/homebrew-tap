# homebrew-tap

Official Homebrew tap for [Orvpass](https://github.com/krtvysinghh/Orvpass) — a lightning-fast, military-grade, open-source password manager.

## Install

```bash
brew tap krtvysinghh/tap
brew install --cask orvpass
```

Or in one command:

```bash
brew install --cask krtvysinghh/tap/orvpass
```

## Uninstall

```bash
brew uninstall --cask orvpass
brew untap krtvysinghh/tap
```
